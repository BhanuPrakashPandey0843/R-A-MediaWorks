# R&A Media Works

Official website for **R&A Media Works**, developed using **Next.js 16**, **React 19**, and **Tailwind CSS 4**.

This project has been built with a strong focus on modern UI/UX, performance, responsiveness, scalability, accessibility, and maintainability. The website is designed to provide a premium digital experience while showcasing the agency's services, portfolio, and brand identity.

## Installation

Clone the repository.

```bash
git clone https://github.com/BhanuPrakashPandey0843/R-A-MediaWorks.git
```

Navigate into the project.

```bash
cd R-A-MediaWorks
```

Install dependencies.

```bash
npm install
```

---

## Running the Development Server

Start the local development server.

```bash
npm run dev
```

The application will be available at:

```
http://localhost:3000
```

---

## Production Build

Create a production build.

```bash
npm run build
```

Start the production server.

```bash
npm run start
```

---

## Linting

Run ESLint.

```bash
npm run lint
```
